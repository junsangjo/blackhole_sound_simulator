# [Blackhole time and sound simulator] :blackhole:
블랙홀 시간과 사운드에 대한 시물레이터를 만들었습니다.
블랙홀안에 가까워질 수록 물리적인 시간은 느리게 흘러간다는 것이 현대의 이론입니다.

프로그래밍으로 블랙홀 시물레이터를 직접 구현하여 블랙홀을 구성하는 수학과 물리적 과정들을 확인하보고

청각과 이를 융합하여, 소비하는 이에게 더 직접적으로 다가오도록 하였습니다.
---------
## 블랙홀을 구성하는 수식

* 슈바르츠실트 반지름
- 공식과 사용이유

* 사건의 지평선
- 공식과 사용이유

* 시간 지연율
- 공식과 사용이유

* 슈바르츠실트 계량
- 공식과 사용이유
---------
## 낙하함수
 공식이 필요하구요

 현재 시물레이터에서는 우주선이 낙하하며 블랙홀에 다가갑니다. 이를 표현하기위해 낙하함수 구현하여 업데이트 했습니다.
